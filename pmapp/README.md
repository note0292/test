# PM学習ロードマップ（Android）

システム開発の基礎から、プロダクトマネージャー（PM）として働けるようになるまでを段階的に学ぶ、オフラインで使える学習アプリです。

## 学習の流れ

全 10 ステップ・38 レッスン（合計 約 8 時間）。各レッスンは次の流れで進みます。

1. **このレッスンのゴール**
2. **解説**（2〜3 セクション）
3. **要点まとめ**
4. **現場ではこうなる** — 実務での具体例
5. **やってみよう** — 自分で書いて考える課題（端末に保存）。書いた後に回答例を確認できる
6. **理解度チェック** — 3 問。60% 以上でレッスン修了

| STEP | テーマ | レベル |
| --- | --- | --- |
| 1 | システム開発と PM の全体像 | 入門 |
| 2 | IT の基礎知識（Web の仕組み、API、DB、クラウド、セキュリティ） | 入門 |
| 3 | ソフトウェア開発のプロセス（ウォーターフォール、アジャイル、スクラム、テスト、CI/CD） | 基礎 |
| 4 | 顧客とユーザーを理解する（課題発見、インタビュー、ペルソナ、MVP） | 基礎 |
| 5 | 戦略とロードマップ（ビジョン、市場分析、優先順位付け） | 実践 |
| 6 | 要件定義（PRD、ユーザーストーリー、UI/UX、非機能要件） | 実践 |
| 7 | チームと開発を進める（見積もり、バックログ、協働、意思決定） | 実践 |
| 8 | データで判断する（KPI、ファネル、A/B テスト、SQL） | 実践 |
| 9 | リリースと成長（GTM、ビジネスモデル、LTV/CAC、障害対応） | 応用 |
| 10 | PM として働き始める（キャリア、面接対策、最初の 90 日） | キャリア |

## その他の機能

- **次に学ぶレッスン** — ホームに、まだ修了していない最初のレッスンを表示
- **間違えた問題を復習** — 前回まちがえた問題をまとめて解き直し
- **修了テスト（30 問）** — 全ステップから均等に出題し、最後にまとめて採点（80% で合格）
- **用語集** — 101 語。検索できる
- **学習記録** — ステップ別の進み具合と正答率、学習日数・連続学習日数
- 選択肢は毎回シャッフル

学習記録は端末内（SharedPreferences）にのみ保存されます。

## インストール

1. GitHub の **Actions** タブ → 最新の「Android build」実行を開く
2. Artifacts の `pmlearn-debug-apk` をダウンロードして解凍
3. `pmapp-debug.apk` を Android 端末に転送してインストール（「提供元不明のアプリ」の許可が必要）

Android 8.0（API 26）以上に対応しています。

## 開発

```sh
./gradlew :pmapp:testDebugUnitTest   # 教材データの検証とロジックのテスト
./gradlew :pmapp:assembleDebug       # APK のビルド
```

### 教材の追加・編集

教材は `src/main/assets/curriculum/` にあります。

- `stageNN.json` — ステップごとのレッスン（`sections` / `keyPoints` / `example` / `exercise` / `quiz`）
- `glossary.json` — 用語集（`stageId` で関連するステップを指定）

本文（`body` など）は空行で段落を分け、`・` で始まる行は箇条書き、`1. ` で始まる行は番号付きの行として表示されます。
理解度チェックの `answer` は正解の選択肢の番号（0 始まり）で、表示時に選択肢はシャッフルされます。
`CurriculumTest` が id の重複や `answer` の範囲、必須項目の有無などを検査します。
