# 準1級クエスト（統計検定準1級 対策アプリ・ゲーム版）

統計検定準1級の合格を目指すための、オフラインで使える学習用 Android アプリです。
**毎日3分・1ステージずつ遊び、180日（約半年）で試験を受けられる状態を目指す**ゲーム形式にしています。

数式は TeX 記法で書かれ、同梱の [KaTeX](https://katex.org/) で教科書と同じ見た目に描画します。

- アプリ名「準1級クエスト」、アプリ ID `com.note0292.statprep.quest`（紫のアイコン）
- 以前の版とは別アプリなので、同じ端末に並べてインストールできます（学習記録はそれぞれ別）
  - Unicode 表記版：アプリ ID `com.note0292.statprep`、コミット `4f41618`
  - TeX 版：アプリ ID `com.note0292.statprep.tex`、コミット `06752b4`

## ゲームのしくみ

- **180日・6ワールド**：はじまりの森 → 確率の平原 → 推測の山脈 → モデルの海 → 応用の塔 → 試験の城。
  微分積分・線形代数の準備から始め、準1級の全分野の定理・例題・問題（計338枚のカード）を Day 1〜150 に均等に割り振っています
- **1日1ステージ（約3分・最大8枚）**：その日の新しいカード2〜3枚＋復習カード。
  定理は「読んで覚える → 後日、名前から内容を思い出す」、例題は「自分で解いてから解答を確認」、問題は選択式
- **間隔反復**：思い出せたカードは 1 → 4 → 10 → 25 → 60 日後と間隔を空けて再登場し、忘れたカードは早めに戻ってきます
- **ボス戦**：各ワールドの 30 日目。そのワールドで学んだ問題から 6 問、6 割正解で撃破（何度でも挑戦可）
- **総仕上げと最終試験**：Day 151〜179 は復習のみ、Day 180 は全分野から 10 問の最終試験
- **合格力**：準1級の出題範囲のカードがどれだけ定着したか（%）。80% が目標
- **XP・レベル・称号・連続クリア日数・バッジ**、3分以内クリアや全問正解のボーナス
- **休んでも大丈夫**：予定より遅れているときは 1 日 2 ステージまで遊べます
- **おかわり復習**：その日のステージをクリアした後、復習期限の来たカードだけを追加で解けます（日数は進みません）。
  シミュレーションでは、毎日1ステージだけだと 180 日目の合格力はおよそ 55〜75%、おかわり復習も続けると 80% 以上に届きます

ホームの「自習モード」から、従来のテキスト・分野別演習・模擬試験なども使えます。

## 自習モードの機能

- **ランダム10問** — 未回答の問題を優先して出題
- **分野別に学習** — 出題範囲 12 分野ごとに演習（分野ごとの進み具合・正答率を表示）
- **苦手問題を復習** — 前回不正解、または正答率 60% 未満の問題を苦手な順に出題
- **ブックマーク** — 気になる問題を保存してまとめて解き直し
- **模擬試験（30問）** — 準1級の出題範囲の全分野から問題数に比例して出題。本番同様その場で正誤を出さず、最後にまとめて採点（経過時間 / 90 分を表示）
- **テキスト（解説・証明）** — 全 16 章・87 レッスン（定理と証明 145、例題 98）。各レッスンは解説 → 定理と証明（タップで表示）→ 例題（解答はタップで表示）の構成。章末に公式まとめと練習問題への導線。読了状況を記録
- **学習記録** — 分野別正答率、学習日数・連続学習日数
- 選択肢は毎回シャッフルされるので、位置で答えを覚えてしまうことを防ぎます
- 結果画面で「間違えた問題だけ解き直す」が可能
- 解説から「テキストで復習する」で該当する章へ移動
- **発展分野（オプション）** — 設定で「効果測定・A/Bテスト」「因果推論」の章と問題を追加できます（初期状態はオフ）

## 収録分野

基礎（準備）：微分積分 / 線形代数 — 統計で使う数学を高校レベルから大学レベルまで必要な部分に絞って解説（模擬試験には出題しない）

確率・確率分布 / 推定 / 仮説検定 / 回帰分析・線形モデル / 多変量解析 / 分散分析・実験計画 /
分割表・カテゴリカルデータ / 時系列解析 / ベイズ統計 / ノンパラメトリック・リサンプリング /
確率過程・シミュレーション / 標本調査・欠測データ

発展（設定でオン）：効果測定・A/Bテスト / 因果推論

## インストール

1. GitHub の **Actions** タブ → 最新の「Android build」実行を開く
2. Artifacts の `statprep-quest-apk` をダウンロードして解凍
3. `statprep-quest-debug.apk` を Android 端末に転送してインストール（「提供元不明のアプリ」の許可が必要）

Android 8.0（API 26）以上に対応しています。

## 開発

```sh
./gradlew testDebugUnitTest   # 問題データの検証とロジックのテスト
npm install --no-save katex@0.16.22 && node tools/check-tex.js   # 全数式を KaTeX で検証
./gradlew assembleDebug       # APK のビルド
```

Kotlin + Jetpack Compose（Material 3）。学習記録は端末内（SharedPreferences）にのみ保存されます。

### 問題の追加

`app/src/main/assets/questions.json` に追記します。

```json
{
  "id": "prob-013",
  "category": "probability",
  "question": "問題文（数式は $\\bar{X}$ のように TeX で書く）",
  "choices": ["$\\dfrac{1}{n}$", "選択肢2", "選択肢3", "選択肢4"],
  "answer": 0,
  "explanation": "解説"
}
```

- `answer` は正解の選択肢の番号（0 始まり）。表示時に選択肢はシャッフルされます
- `category` は `Category`（`data/Question.kt`）の `id` のいずれか
- 数式はインライン `$...$`、別行立て `$$...$$` で囲み、1 行の中で閉じます（JSON 内ではバックスラッシュを `\\` と書きます）
- `QuestionBankTest` が id の重複や `answer` の範囲などを、`tools/check-tex.js` が数式の文法と数式外に残った記号を検査します

### テキストの編集

`app/src/main/assets/textbook/<分野id>.json` が 1 章に対応します。各レッスンは `body`（解説）、`theorems`（`title`・`statement`・`proof`）、`examples`（`question`・`solution`）からなります。`TextbookTest` が全分野の章の存在や証明の欠落を検査します。
