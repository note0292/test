# 統計検定準1級 対策アプリ（Android）

> このリポジトリには、PM（プロダクトマネージャー）を目指す人向けの学習アプリ [`pmapp/`](pmapp/README.md) も含まれています。

統計検定準1級の合格を目指すための、オフラインで使える学習用 Android アプリです。

## 機能

- **ランダム10問** — 未回答の問題を優先して出題
- **分野別に学習** — 出題範囲 12 分野ごとに演習（分野ごとの進み具合・正答率を表示）
- **苦手問題を復習** — 前回不正解、または正答率 60% 未満の問題を苦手な順に出題
- **ブックマーク** — 気になる問題を保存してまとめて解き直し
- **模擬試験（30問）** — 全分野から問題数に比例して出題。本番同様その場で正誤を出さず、最後にまとめて採点（経過時間 / 90 分を表示）
- **公式・要点ノート** — 分野ごとの重要公式を一覧で確認
- **学習記録** — 分野別正答率、学習日数・連続学習日数
- 選択肢は毎回シャッフルされるので、位置で答えを覚えてしまうことを防ぎます
- 結果画面で「間違えた問題だけ解き直す」が可能

## 収録分野

確率・確率分布 / 推定 / 仮説検定 / 回帰分析・線形モデル / 多変量解析 / 分散分析・実験計画 /
分割表・カテゴリカルデータ / 時系列解析 / ベイズ統計 / ノンパラメトリック・リサンプリング /
確率過程・シミュレーション / 標本調査・欠測データ

## インストール

1. GitHub の **Actions** タブ → 最新の「Android build」実行を開く
2. Artifacts の `statprep-debug-apk` をダウンロードして解凍
3. `app-debug.apk` を Android 端末に転送してインストール（「提供元不明のアプリ」の許可が必要）

Android 8.0（API 26）以上に対応しています。

## 開発

```sh
./gradlew testDebugUnitTest   # 問題データの検証とロジックのテスト
./gradlew assembleDebug       # APK のビルド
```

Kotlin + Jetpack Compose（Material 3）。学習記録は端末内（SharedPreferences）にのみ保存されます。

### 問題の追加

`app/src/main/assets/questions.json` に追記します。

```json
{
  "id": "prob-013",
  "category": "probability",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answer": 0,
  "explanation": "解説"
}
```

- `answer` は正解の選択肢の番号（0 始まり）。表示時に選択肢はシャッフルされます
- `category` は `Category`（`data/Question.kt`）の `id` のいずれか
- `QuestionBankTest` が id の重複や `answer` の範囲などを検査します
